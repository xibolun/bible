# Bible · 圣经

一款离线圣经桌面阅读器，支持 macOS、Windows 和 Linux。

## 特性

- 仅内置完整中文和合本简体字 CUV；可在译本管理中从 CrossWire 下载中文／英文译本，或导入本地文件，安装兼容译本后支持上下对照。
- [本地译本导入](docs/edition-import.md)：支持 MyBible、MySword、theWord、OSIS、Zefania XML 和 SWORD ZIP 的明确子集，预览后安装，可停用、替换、恢复版次及删除。
- 书卷目录、按钮组下方自动换行的章号、逐句节号，支持左右方向键翻章。
- 离线经文搜索，支持 `%`、`_` 通配符和点击结果定位，例如 `起%神` 可找到创世记 1:1。
- 文字选区高亮，复制可选择全书名／简称、译本标识、整段或逐节引用。
- 离线原文字典：信望爱 CBOL 中文释义、希伯来文／希腊文字形、音译和 H/G 编号查询；可由选中经节查看 KJV Strong’s 关联词组。
- 经文卡片预览与 PNG 导出，提供方图、竖图、配色与引用样式。
- 中英文界面、字号和复制偏好本地保存；经文、高亮和设置离线可用。
- 清爽浅色、暖纸色、柔绿色和静谧夜读四种阅读主题，目录与控件同步切换并保存。

## 安装

在 [Releases](https://github.com/xibolun/bible/releases) 选择与系统、处理器匹配的安装包。公开附件提供以下四种组合，文件名包含版本号和架构。

| 系统       | 架构                                   | 安装包                              |
| ---------- | -------------------------------------- | ----------------------------------- |
| macOS 12+  | Apple Silicon（arm64）／Intel（amd64） | `.dmg`                              |
| Windows 11 | Intel、AMD 64 位（amd64）              | `-installer.exe`                     |
| Linux      | Intel、AMD 64 位（amd64）              | `.deb`                              |

- **macOS**：打开 DMG，将 Bible 拖入 Applications。当前应用使用临时签名，尚未公证。
- **Windows**：运行对应架构的安装器。需要 Microsoft WebView2 Runtime；当前安装包未签名。
- **Linux**：推荐 Ubuntu 24.04 及以上或兼容系统，安装对应 `.deb` 后运行 `bible`。依赖 GTK4、WebKitGTK 6.0 和桌面文件对话框服务，包管理器会安装声明的依赖。受限用户命名空间环境的配置见开发文档。

发布说明的折叠区域提供四个安装包的 SHA-256。其他架构、便携包、构建清单和原生验证报告保留在 Actions 工件中。卸载保留用户的标记和设置。

## 使用

点击书卷和章号阅读；在顶部选择对照译本。单击经文行或节号可选择整节，Shift 单击可连续选择；拖选部分文字和双击选词仍可使用。选区旁的工具栏提供高亮、复制和卡片操作。

点击「原文字典」，或选中经节后点击「原文注解」，直接查看中文含义；中文释义保留来源繁体文字，完整词典原文、英文释义和统计可展开。经节关联采用 KJV Strong’s 标注，不代表中文译本逐词对齐。

点击「经文搜索」在选定译本全书中查找。默认匹配整节中的内容；`%` 匹配任意长度，`_` 匹配一个字，`\%` 和 `\_` 查找符号本身。点击结果跳到对应经节并短暂高亮关键字，搜索列表保持打开，可继续点击其他结果；点击正文收起搜索栏。最近 20 条搜索按译本保存到本机，可点击重用或清空。

按钮和左右方向键可跨书卷连续翻章，长按方向键可持续切换，松开即停。卷末进入下一卷第一章，卷首返回上一卷最后一章，仅全书首尾停止；输入和弹层内保留控件本身的键盘操作。

在「设置」中选择阅读主题、复制样式、字号和界面语言。中文数字章号直接连接节号（如约三16），阿拉伯数字章号使用冒号（如约3:16）。出处括号可选【】、「」、[] 或无，正文不加括号；复制、卡片和投影使用相同格式，也可在对应编辑器内单独调整。全局字号同步缩放界面与经文，原有阅读字号作为正文基准保留，PNG 卡片的字号和尺寸独立设置。源码入口位于设置中。

Ctrl+, 打开设置，Ctrl+F 打开或聚焦经文搜索，Ctrl+C 按复制设置复制所选经文，Ctrl+V 在输入框粘贴，Ctrl+Q 保存偏好后退出。macOS 使用 ⌘ 代替 Ctrl（设置为 ⌘+,）；输入框保留标准复制／粘贴。浏览器预览使用退出快捷键时会提示直接关闭标签页。

按 F8 或点击「投影 F8」打开投影控制，统一使用“快速经文”一行完成录入。书卷输入支持中文、英文／ID、拼音全拼和首字母，例如 `John`、`1 John`、`yuehan`、`yhfy`、`csj`，并提供下拉建议。按 Tab 确认书卷并进入章，再按 Tab 进入起始节；章和节既可直接输入，也可从建议中选择。每次聚焦都会全选已有值，直接键入即可覆盖，兼容全角数字及拼音声调。

在起始节按 Enter 立即投放单节；若要多节，再按 Tab 显示并进入截止节，填写后 Enter 投放范围。书卷／章的 Enter 用于确认并前进，Shift+Tab 反向移动。点击「＋」或在快速经文中按 Ctrl／⌘+Enter，把当前经文加入准备清单；新增后返回并全选书卷，方便连续录入。起始节留空可投放整章。切换卷章或译本后按实际经节校验，加载中可以继续输入，提交会等待对应章节；错误范围和缺节不会替换成相邻经文。

多卷、多章可逐段加入同一清单，删除或调整顺序后点击「投放清单」同屏显示，每段保留自己的出处；准备清单的修改不会立即改变观众画面。最多12段、600节；整组通过校验后才更新画面，无效、倒序或缺节范围会报错并保留当前内容。每个范围限同章，多个范围可来自不同章卷，统一使用当前所选译本。多段分页按「每段每页经节」分别取经节，已展示完的段不重复；单段分页保持原有行为。

主窗口可调整投影字号、背景／文字颜色、对齐、每页经节数和经文出处样式，设置独立保存。默认白板配色，长经文自动缩小以适应画面。将投影窗口拖到第二屏，按 F11 全屏，Esc 退出全屏；左右箭头或 PageUp／PageDown 翻页，B 黑屏／恢复，F8 回到控制。关闭主窗口会同时关闭投影。浏览器原型需允许弹出窗口，并在投影页自行使用全屏快捷键。

投影主题可选择白板、夜空、暖纸、青绿、深蓝或暮紫，主题预览可直接点击。主题包含协调的颜色及排版，保留字号、分页与出处格式；手动调整颜色或对齐会切到「自定义」。主题和自定义颜色重启后保留，经文准备清单仅保存当前会话。
